- 交付文件目录：`artifacts/windows/`，二进制产物不纳入 Git。

## 安装与升级

优先使用 `ModelGym_1.27.0_x64-setup.exe`。原来使用 MSI 部署时，使用 `ModelGym_1.27.0_x64_zh-CN.msi` 保持同类安装器升级。

安装前退出原 RackTop，包括托盘实例。ModelGym 沿用原应用标识，旧进程未退出时新进程可能激活旧窗口。
升级保留服务器配置、历史数据库、系统凭据和 SSH 密钥。手工解压的旧版没有安装记录，其文件夹不会自动删除，请改用 ModelGym 快捷方式。

便携 ZIP 包含 `ModelGym.exe` 和使用文档，解压后运行；机器仍需要 WebView2。
本次产物未做发布者 Authenticode 签名。文件校验值见交付目录中的 `SHA256SUMS.txt`。
